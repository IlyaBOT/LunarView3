# ATmega328P: прошивка Dumper Lite

Bare-metal C для **ATmega328P-AU, внешний кварц 16 МГц**, без Arduino и загрузчика. Только чтение параллельной ROM на 5 В, адреса 0…65535. Файл `build/dumper_lite.hex` собран; чтение реальной EPROM ещё не испытывалось.

## Сборка и загрузка

Из корня проекта: `powershell -ExecutionPolicy Bypass -File firmware/lite/build.ps1`. Скрипт использует установленный AVR-GCC из Arduino AVR Boards, включает предупреждения как ошибки и создаёт ELF/HEX. Исходник — `main.c`, общая проверяемая логика размера и CRC — `protocol_core.h`.

Записывайте **dumper_lite.hex через ISP** своим программатором. Внешний кварц 16 МГц должен быть выбран fuse-настройками, деление CKDIV8 отключено. Сначала прочитайте существующие fuses и сверьте режим генератора с даташитом. Автоматического изменения fuses и записи в устройство в этой задаче не было. Прошивка занимает адреса с нуля; для неё не нужен Arduino bootloader/BOOTRST. Сохраняйте включённый ISP и функцию RESET. Не подключайте одновременно конкурирующие источники питания USB и ISP.

Если используете уже настроенный USBasp, пример команды записи: `avrdude -c usbasp -p m328p -U flash:w:firmware/lite/build/dumper_lite.hex:i`. Это пример для конкретного программатора, не команда, выполненная на вашем ПК. Параметры другого ISP надо заменить.

## Распиновка

| Сигнал | GPIO |
|---|---|
| D0…D5 | PC0…PC5, постоянно входы, слабые подтяжки включены |
| D6 / D7 | PD4 / PD5, постоянно входы |
| CE# / OE# | PD6 / PD7; HIGH при ожидании и смене адреса |
| 74HC595 LATCH / SER / SCK | PB2 / PB3 / PB5 |
| RGB R / G / B | PB0 / PB1 / PD2, общий анод, LOW включает |
| UART RX / TX | PD0 / PD1 |

Два регистра: сначала A8…A15 в U3, затем A0…A7 в U2; MSB first, SPI mode 0, 1 МГц. EPROM включается после защёлкивания адреса, выдержка перед чтением — 10 мкс. CE#/OE# снова HIGH до передачи байта. Данные никогда не переключаются в выходы. Для КР573РФ5 выберите запись на 2048 байт и используйте изготовленный адаптер; уровни на реальной сборке ещё надо проверить.

Красный RGB — нет логического соединения (RESET и CON:STOP). Янтарный R+G — подключённое устройство ожидает команду. Чтение — зелёный, 500 мс включён / 500 мс выключен; затем снова янтарный. Ошибка команды сохраняет цвет текущего состояния. Фиолетовый режим записи в Lite не вызывается. RX/TX показывают UART аппаратно и не требуют кода. Watchdog 1 с обслуживается во время ожидания/передачи. Команда длиннее буфера, неправильные байты UART и незавершённая строка отбрасываются; частичная команда имеет тайм-аут 1 с.

## UART и протокол

На компьютере **115200, 8N1**, без flow control. При кварце 16 МГц выставлены U2X=1, UBRR=16: физическая скорость AVR около 117647 бод, отклонение +2,12% от 115200. Это ближайший делитель; точно 115200 с этим кварцем не получается. Надёжность именно вашей пары AVR/CH340 проверяется чтением и CRC, не утверждается по одной компиляции. Формула делителя описана в [даташите ATmega328P](https://ww1.microchip.com/downloads/aemDocuments/documents/MCU08/ProductDocuments/DataSheets/Atmel-7810-Automotive-Microcontrollers-ATmega328P_Datasheet.pdf).

Полный контракт: [protocol_lite.md](../../docs/protocol_lite.md). Сначала необходим CON:START; он возвращает название, ревизию, версию, ID и дату сборки. CON:STOP закрывает сессию, оставляет CE#/OE# HIGH и ждёт нового подключения. После `READ:32768\n` ответ — `ACK:` + 65536 HEX-символов + LF, затем отдельная строка `CRC:XXXX` + LF. Нет разделителей между байтами. Сначала старшая тетрада; адреса возрастают от нуля. Размер принимается строго десятичный от 1 до 65536. Объём 65536 обрабатывается 32-битным счётчиком, адрес шины 16-битный.

Прошивка не определяет тип/ID EPROM: выбор в каталоге задаёт длину и режим выводов PINS:27C512 / 27C256 / 27C128. Для NM27C256 удерживается HIGH на A15/VPP1, для NM27C128 — на A15/VPP1 и A14/PGM27. Младшие адреса начинаются с нуля. RF5 через адаптер использует 27C512. Она не включает повышенные напряжения и не программирует микросхемы. Во время дампа принимается CON:STOP: передача прекращается на границе байта, CE#/OE# выключаются; неполный ACK завершается LF, затем идут ERR:STOPPED и CON:STOP, без CRC. Другие команды во время дампа отбрасываются. Штатное отключение проверяет подтверждение STOP; закрытие во время чтения отправляет STOP перед закрытием порта без ожидания ответа. При обрыве программа не разрешает сохранять дамп как подтверждённый.

## Идентификатор и версия

Измените простые #define в [identity.h](identity.h): DUMPER_NAME, DUMPER_REVISION, FIRMWARE_VERSION. Текст ответа хранится во Flash через PSTR, целиком в SRAM не копируется. build.ps1 генерирует build/build_metadata.h: FIRMWARE_BUILD_ID — первые 10 HEX-знаков SHA-256 исходников/настроек, FIRMWARE_BUILD_DATE — местная дата сборки dd.MM.yyyy. ID — отпечаток исходников, не серийный номер экземпляра платы.

Можно переопределить поля без изменения исходника:

```powershell
powershell -ExecutionPolicy Bypass -File firmware/lite/build.ps1 -Revision 2 -FirmwareVersion 1.1.0 -BuildId a8191hbz1 -BuildDate 12.10.2026
```

-DeviceName меняет название, -OutputDirectory позволяет собрать другую ревизию отдельно. Прямая сборка без скрипта использует дату __DATE__ и ID manual.

Итоговая сборка AVR-GCC 7.3.0 с -Wall -Wextra -Werror: Flash 2396 байт, статическая SRAM 93 байта (включает буфер команды, не включает стек). Идентификатор подтверждён в секции .text ELF; в .data отсутствует. Реальный обработчик команд, выводы RGB и дампы проверены на ПК с имитацией регистров. Это проверка поведения C-кода без моделирования времени CPU и электрических уровней. [Отчёт](../../validation/lite-update-2026-10-12/REPORT.md).
