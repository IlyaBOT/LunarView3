# UART Lite 2 — 115200, 8N1

Контракт `firmware/lite` и `app-win_forms`; прежний Stage 2 использует отдельный протокол. ASCII, LF завершает команду, CRLF принимается. Формат `<ключ>:<аргумент>` / `<ключ>:<ответ>`. Выполняется одна команда; приложение блокирует кнопки и выбор COM/ROM на время операции.

| Команда | Ответ |
|---|---|
| `CON:START` | `CON:<идентификатор>` + LF, затем `INFO:LITE2,MAX=65536,CRC16=1,PINS=1` + LF |
| `CON:STOP` в ожидании | `CON:STOP` + LF; сессия закрывается, CE#/OE# HIGH |
| `INFO:` | `INFO:LITE2,MAX=65536,CRC16=1,PINS=1` + LF; доступно без соединения |
| `PING:` | `ACK:PONG` + LF |
| `PINS:27C512` | `ACK:PINS` + LF; обычный 16-битный адрес |
| `PINS:27C256` | `ACK:PINS` + LF; A15/VPP1 постоянно HIGH |
| `PINS:27C128` | `ACK:PINS` + LF; A15/VPP1 и A14/PGM27 постоянно HIGH |
| `READ:N` | `ACK:` + ровно `2*N` HEX-символов + LF, затем `CRC:XXXX` + LF |
| Ошибка | `ERR:NOTCONNECTED`, `ERR:PINS`, `ERR:SIZE`, `ERR:COMMAND`, `ERR:FRAME`, `ERR:TIMEOUT` + LF |

После RESET сессия отключена, RGB красный. START открывает сессию и сбрасывает режим выводов на 27C512; RGB становится янтарным. Повторная START допустима. READ/PINS без сессии запрещены. STOP оставляет устройство в ожидании нового START, RGB красный. Ожидание команды при подключённом устройстве — янтарное.

Пример ответа (поля задаются при сборке прошивки):

```text
CON:Lunar Dumper (Rev. 1) | Firmware: v.1.0.0 (build a8191hbz1) 12.10.2026
INFO:LITE2,MAX=65536,CRC16=1,PINS=1
```

Приложение отображает сам текст CON без подстановки своей версии. Совместимость проверяется по второй строке INFO. Старые Lite 1 и Stage 2 отвергаются; обновите приложение и Lite HEX вместе.

`N` — строго десятичное число 1…65536, адреса начинаются с нуля. Для 27C256 максимум 32768, для 27C128 — 16384. Фиксированные HIGH относятся к управляющим выводам выбранной ROM, а не к выбору верхнего банка памяти. Длина READ сама по себе не меняет режим: чтение первых 32768 байт NM27C512 сохраняет PINS:27C512. Перед каждой операцией приложение явно выбирает PINS из каталога.

READ:4 для байтов FF A1 07 15 возвращает первую строку `ACK:FFA10715`. FF — два ASCII-символа, кодирующие **один** байт ROM. Границы порций Serial.Read() могут проходить посередине HEX-пары или заголовка. Парсер сохраняет неполную тетраду между порциями.

CRC16/CCITT-FALSE: начальное FFFF, полином 1021, без отражения и финального XOR; считается по исходным байтам ROM. Контрольный вектор ASCII `123456789` → 29B1. Дамп подтверждается только после точного количества HEX-символов и правильной CRC-строки. Повреждённый/неполный дамп сохранять нельзя. Тайм-аут без данных — 3 с, общий предел `10 + N/2000` секунд.

Во время чтения зелёный RGB: 500 мс включён / 500 мс выключен. STOP во время чтения прекращает передачу на границе байта, выключает CE#/OE#, закрывает сессию и выдаёт LF, `ERR:STOPPED` + LF, `CON:STOP` + LF. CRC неполного дампа не передаётся. Другие команды в процессе передачи игнорируются. Частичная STOP-строка на границе окончания дампа остаётся в парсере и завершается уже в ожидании.

При открытии SerialLink использует DTR для RESET, затем START. Штатное отключение проверяет подтверждение STOP до закрытия порта. Закрытие окна во время операции отменяет чтение на ПК и отправляет STOP перед закрытием порта (ответ уже не ожидается). После физического обрыва USB отправку подтвердить невозможно; повторное подключение выполняет RESET/START.

Данные передаются по одному без буфера всей ROM в SRAM AVR. Для 65536 байт HEX занимает 131072 символа: теоретически 11,38 с на 115200, 8N1, плюс работа GPIO/USB. Физическая скорость AVR с 16 МГц — около 117647 бод (+2,12%). CRC проверяет передачу, а не правильность электрического чтения EPROM.
