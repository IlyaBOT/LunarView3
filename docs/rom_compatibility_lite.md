# Варианты ROM для Lite

Проверено по документации изготовителей 12.10.2026. Каталог содержит четыре записи для DIP-корпусов National/Fairchild и КР573РФ5 через существующий адаптер. Выбор делает пользователь, ID не считывается.

| ROM | Размер | Режим выводов сокета | Адаптер |
|---|---:|---|---|
| NM27C512 | 65536 байт | PINS:27C512, обычный адрес A0…A15 | Не требуется |
| NM27C256 | 32768 байт | PINS:27C256, вывод 1 VPP вместо A15 постоянно HIGH | Не требуется |
| NM27C128 | 16384 байт | PINS:27C128, VPP1 и PGM27 вместо A14 постоянно HIGH | Не требуется |
| КР573РФ5 | 2048 байт | PINS:27C512 через адаптер DIP24 → DIP28 | adapter_KR573RF5 |

Основные сигналы и питание 5 В совпадают, но полностью одинаковой функции всех 28 выводов при разном объёме здесь нет. Команда PINS учитывает VPP/PGM без изменения платы: CE#/OE# неактивны при выборе режима; управляющие выводы меняются одновременно на защёлке 74HC595. При чтении NM27C256 VPP должен быть близок к VCC; источник HIGH — выход 74HC595 при малой нагрузке VPP (до 10 мкА по документации ROM). На реальной сборке эти уровни ещё не измерены.

Источники изготовителей, размещённые в архивах:

- [National NM27C512, TL/D/10834](https://deramp.com/downloads/mfe_archive/050-Component%20Specifications/National%20Semiconductor/Memory%20Components/National%20NM27C512.pdf): DIP28, выход HIGH ≥3,5 В.
- [National NM27C256, DS010833, March 1997](https://tvsat.com.pl/PDF/N/NM27C256_NSC.pdf): страницы 2/3, DIP28 VPP1, 5 В, VOH ≥3,5 В, VPP чтения VCC−0,7…VCC, нагрузка VPP до 10 мкА.
- [Fairchild NM27C128, July 1998](https://www.meditronik.com.pl/doc/plus/nm27c128.pdf): страницы 2/3/8/9, DIP28 VPP1/PGM27, 5 В, VOH ≥3,5 В, PGM HIGH при чтении. Вывод о совместимости с входами AVR относится к указанным деталям и режиму чтения.

NM27C64/NMC27C64 не добавлена как прямая замена: [документация Fairchild, Rev. C, страница 3](https://www.alldatasheet.com/html-pdf/148603/FAIRCHILD/NM27C64/1470/3/NM27C64.html) задаёт VOH ≥2,4 В при нагрузке и отдельно почти VCC без нагрузки. Гарантировать такой же запас входного уровня AVR на существующей плате по этому пределу нельзя. Произвольные 27C64/128/256 других изготовителей не подразумеваются совместимыми только по названию.

Более ёмкие DIP32 выходят за пределы 16 адресных линий Lite. Другие советские ROM требуют отдельной проверки: существующий адаптер RF5 фиксирует VPP на выводе 21, который у другой микросхемы может быть адресным.
