Модели RGB и USB перенесены без изменения их исходной геометрии. Для условных моделей указана их отдельная природа; они создаются локальными скриптами проекта.

## Переключение RGB

В 3D сейчас установлен **квадратный SMD 5050**, как выбрал пользователь. Чтобы посмотреть выводной вариант, откройте свойства D1 (Lite) или D2 (полная версия) → **3D Models**: выключите показ `LED_RGB_5050-6.step`, включите `LED_D5.0mm-4_RGB.step`. Установить на реальную плату нужно один LED из двух. Модели отображают сборку; электрическая нумерация и маркировка производителя описаны в `RGB_Mounting.md` каждого проекта.

## Сохранность платы

Изменения выполняются только в узлах `(model …)` сохранённых плат и локальной RGB-посадки. Дорожки, переходы, площадки, координаты компонентов, контур и пользовательская графика сравниваются как дерево KiCad до/после удаления узлов моделей. Отчёт — `validation/3d_update_2026-10-07.json`; промежуточные резервные копии до добавления моделей удалены при очистке 12.10.2026. В проектах оставлены две последние автоматические ZIP-копии KiCad.

Основной Lite обновлён после закрытия редактора: изменены только ссылки и параметры моделей, пользовательская разводка сохранена. [Предпросмотр Lite](../Dumper-Lite/validation/Lite_With_3D.png). Для продолжения работы используйте исходный проект в `Dumper-Lite/`.

Для адаптера RF5 стандартные DIP-24/TSSOP/0603 модели берутся из установленного KiCad. Его нижние круглые штыри показаны отдельной созданной габаритной моделью; размеры и конкретные контакты описаны в README адаптера.
