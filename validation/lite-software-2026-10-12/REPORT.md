# Проверка ПО и экспорта Lite, 12.10.2026

Workspace фактически `I:/ATmega_EPROM-Dumper`; прежний `F:/ATmega_EPROM-Dumper` недоступен.

- AVR-GCC 7.3.0: `firmware/lite/build.ps1`, `-Wall -Wextra -Werror`, Flash 1520 B / static SRAM 22 B. HEX/ELF созданы. В SRAM-оценку не входит стек.
- MSVC 14.44, native C: `tests/lite_protocol_native.c`, проверены границы/переполнение размера, CRC/CCITT-FALSE и все 65536 адресов 16-битной шины. Этот тест использует `protocol_core.h` прошивки, но не исполняет AVR GPIO-код.
- .NET 8 Windows Forms: Release build/publish, 0 ошибок, 0 предупреждений. Solution Visual Studio 2022: `app-win_forms/EpromDumper.sln`. Публикация: `app-win_forms/release`.
- Console tests: 27 проверок; полный поток 1 / 2048 / 32768 / 65536 байт, разбиение в каждом месте короткого ответа, CRC, неверный HEX, неполные/лишние данные, ошибка устройства, несовместимая Stage 2, отмена, обрыв и XML-каталог со всеми атрибутами.
- UI-тест: COM, ROM, connect, refresh, read и save заблокированы при операции; HEX остаётся доступным; после операции блокировка снята, непроверенный дамп сохранить нельзя.
- Предпросмотр `app-win_forms/preview.png` получен через DrawToBitmap из реально собранной формы на демонстрационных данных. Реальный COM не открывался.
- CNC PNG: два цвета без полутонов, одинаковые 7730×4805 px / 2540 dpi / 77,30×48,05 mm; 205 верхних + 50 нижних центров электрических площадок в чёрной области. Нижний слой уже отражён, общая система координат обоих слоёв сохранена.
- Текущая плата: 645 дорожек, 212 переходов, минимум 0,20 mm. 203 перехода 0,30/0,60 mm. См. `board_audit.json`, `cnc_raster_audit.json` и обновлённые CSV в `docs/cnc-k4`.
- DRC: 16 warnings + 2 unconnected errors между участками GND-зоны. Предупреждения: 15 изолированных заливок и 1 dangling GND track. Экспорт не объявлен готовым к производству; подробности в `docs/cnc-k4/README.md`.
- SHA256 исходного PCB после работ совпал с исходным снимком. Электрическая геометрия не изменялась.

Чтение реальной EPROM, UART с CH340, параметры/прошивка реального K4 и чувствительность этого рулона на 455 nm не испытывались. Расчёт лазера условный: номинальная оптическая мощность 3 W, линейная регулировка, равномерный растр. Производственный режим экспозиции не подтверждён.
